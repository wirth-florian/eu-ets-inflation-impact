I recommend using the csv file as it's in tidy data format.

Note that on Eurostat there is no category for CPI122_127 (Other services n.e.c) like in the Weber data.xlsx. In fact ,there is no category for 122 at all! Instead, only 127 is called other services n.e.c.

If we want to include CP123 (personal effects n.e.c), CP124 (social protection), CP125 (insurance) and CP126 (financial services n.e.c) then we might want to compute an average of those prior weights and the one for CP127 (other services n.e.c.).
